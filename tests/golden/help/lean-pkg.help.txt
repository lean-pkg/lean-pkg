usage: lean-pkg help [-h] [--json] [TOPIC|COMMAND ...]

Without an argument: the commands and help topics. With a topic (exit-codes, environment,
formatting): that topic. With a command (`help status`, `help index add`): exactly its --help.
Reads no registry.

positional arguments:
  TOPIC|COMMAND

options:
  -h, --help     show this help message and exit
  --json         machine-readable JSON on stdout
