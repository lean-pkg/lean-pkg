usage: lean-pkg help [-h] [--json] [--commit] [--push] [--no-commit] [TOPIC|COMMAND ...]

Without an argument: the commands and help topics. With a topic (exit-codes, environment,
formatting): that topic. With a command (`help status`, `help index add`): exactly its --help.
Reads no registry.

positional arguments:
  TOPIC|COMMAND

options:
  -h, --help     show this help message and exit
  --json         machine-readable JSON on stdout
  --commit       write commands: pull --ff-only, then commit the registry files (default:
                 $LEAN_PKG_COMMIT=1)
  --push         --commit, then push to origin (default: $LEAN_PKG_PUSH=1)
  --no-commit    never commit or push (overrides the env)
