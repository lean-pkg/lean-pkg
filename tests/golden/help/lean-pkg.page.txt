usage: lean-pkg page [-h] [--write] [--check] [--out PATH] [--site DIR] [--html PATH] [--repo DIR]
                     [--strict-preview] [--allow-private-manuscript] [--agent AGENT] [--json]
                     name

positional arguments:
  name

options:
  -h, --help            show this help message and exit
  --write               replace the marked block in the package README.md (append it when absent);
                        prose outside the markers is untouched. For a gated package whose record
                        says nothing about the docs-only exception, it then turns it on (`update
                        NAME --accept-docs-descendants`, its own registry write), so committing
                        the README keeps the receipts bound
  --check               exit 1 when the README block is missing or stale, the lean-pkg credit is
                        missing, or the Easley sentence has no backing Slurm receipt; with
                        --site/--html also when those files are missing or stale; writes nothing
  --out PATH            write the block here instead; README untouched
  --site DIR            also write DIR/verification.md (the full page) and DIR/coverage.md (every
                        row, its claims, inputs and notes) for MkDocs; with --check, compare them
                        instead
  --html PATH           also write one static HTML file (no script, no external asset) from the
                        same data; with --check, compare it instead
  --repo DIR            read the checkout DIR instead of the registered local_path, for this call
                        only (never saved; for CI): DIR must be a git work tree, and when it has
                        remotes one must be the package's repo; not with --write. Its committed
                        HEAD is read: when the recorded gate receipt does not bind that HEAD (or
                        an evidence-only descendant), the links and Lean statements are read at
                        HEAD, no receipt fact is shown and the page says so; with --check,
                        differences of such a preview from the receipt-bound files are warnings
                        (exit 0)
  --strict-preview      with --check --repo: a preview's differences from the receipt-bound README
                        block and --site/--html files fail the check (exit 1) instead of warning
  --allow-private-manuscript
                        render against manuscript.version 'unposted'; the page then says so
  --agent AGENT         with --write: the lease holder, when the package is leased
  --json                machine-readable JSON on stdout
