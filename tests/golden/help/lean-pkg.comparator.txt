usage: lean-pkg comparator [-h] {attach,config,host-check} ...

positional arguments:
  {attach,config,host-check}
    attach              attach a comparator receipt to a gated package; no status change
                        (`comparator NAME --receipt R` is the same)
    config              write a comparator configuration from claims (--from-claims), report its
                        coverage (--coverage), or move inline sign-off keys (--migrate-signoff)
    host-check          can this host run the comparator; read-only

options:
  -h, --help            show this help message and exit
