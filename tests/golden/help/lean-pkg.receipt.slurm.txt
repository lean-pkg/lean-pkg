usage: lean-pkg receipt slurm [-h] [--job J] [--log PATH] [--commit SHA] [--template] [--check]
                              [--preflight-deps] [--deps-tar PATH] [--deps-dir DIR]
                              [--entries GLOB] [--stdout PATH] [--stderr PATH] [--redact REGEX]
                              [--sacct-file F] [--artifacts DIR] [--artifacts-manifest NAME]
                              [--checker TEXT] [--repo DIR] [--out PATH] [--compress-log]
                              [--append-readme] [--readme-heading TEXT] [--readme-line TEXT]
                              [--tar-sha256 HEX] [--json]

options:
  -h, --help            show this help message and exit
  --job J               the Slurm job id (job_id becomes slurm-J); required unless --template or
                        --check
  --log PATH            the job's raw verify log (required unless --template); when it has no
                        `checker:` line, --checker TEXT is required
  --commit SHA          the verified commit; must exist in --repo; required unless --template or
                        --check
  --template            print a minimal sbatch wrapper whose .out/.err/log meet every check below
                        (placeholders for the package's own commands); needs no other flag
  --check               preflight the files of a finished (trial) job: every seal, stderr and log-
                        line check, each problem named; no sacct (unless --sacct-file), commit
                        checks only with --commit; writes nothing, exit 0/1
  --preflight-deps      before submitting: check that the staged dependency cache (--deps-tar or
                        --deps-dir) holds, at the lake-manifest.json pins committed at --commit
                        (default HEAD), the built .olean and .ilean of every external module in
                        the import closure of the entry files the verifier elaborates (--entries);
                        reads the committed tree, builds and writes nothing, exit 0/1
  --deps-tar PATH       with --preflight-deps: the DEPS_TAR tarball the job will restore (gzip,
                        bzip2, xz or plain; read in one pass, never extracted)
  --deps-dir DIR        with --preflight-deps: a directory holding .lake/packages, instead of
                        --deps-tar
  --entries GLOB        with --preflight-deps: a glob (relative to the package directory; ** = any
                        directories) of the .lean files the verifier elaborates, repeatable;
                        replaces the default Verify/**/*.lean, Audit/**/*.lean,
                        OwnedAudit/**/*.lean, **/AxiomCheck*.lean, **/TypeCheck*.lean,
                        **/Examples*.lean, **/OwnedAudit*.lean
  --stdout PATH         the job's stdout (.out): verify-log-sha256 = sha256(raw log), pre-
                        manifest-sha256 = post-manifest-sha256 = sha256(lake-manifest.json at the
                        commit); without it the log must carry its own seal
  --stderr PATH         the job's stderr (.err); must be empty
  --redact REGEX        also replace matches with <redacted> (repeatable); the built-in prefixes
                        are always redacted to <USER> instead (/tmp/<USER>-job, /scratch/<USER>/)
  --sacct-file F        saved output of `sacct -j J --format=JobID,State,ExitCode,Elapsed,TotalCPU
                        -P -n` (a host without Slurm)
  --artifacts DIR       the collected copy of the job's sealed artifact directory (the template's
                        ARTIFACTS_DIR): the manifest's sha256 must be the --stdout artifacts-
                        manifest-sha256 line and every file under DIR is rehashed against it
                        (missing, extra, changed files, symlinks, special files, path traversal
                        and duplicate entries refuse); the receipt gains artifacts_manifest_sha256
                        and the manifest is written beside it. Needs --stdout
  --artifacts-manifest NAME
                        the manifest's file name inside --artifacts DIR (default artifacts.sha256)
  --checker TEXT        the exact checker command or mode (default: the log's `checker:` line)
  --repo DIR            the package checkout (default: the current directory)
  --out PATH            receipt path (default <repo>/.lean-receipts/<commit12>-slurm-<J>.json);
                        the redacted log is written beside it as
                        <commit12>-slurm-<J>-verify.redacted.log
  --compress-log        write the redacted log as deterministic gzip <...>-verify.redacted.log.gz
                        (level 9, mtime 0, no file name) instead of the plain .log; report_sha256
                        stays the SHA-256 of the uncompressed log and the receipt gains
                        report_compressed {format: gzip, sha256 of the .gz, bytes uncompressed};
                        gate decompresses (bounded) and checks report_sha256. Restore: gzip -dc
                        X.log.gz > X.log. Without it, a log over 90 MiB prints a WARN naming this
                        flag
  --append-readme       append the entry block to README.md beside the receipt (created if absent;
                        an entry already naming the receipt is not repeated)
  --readme-heading TEXT
                        the entry heading after the short commit (default: lower-tier receipt,
                        Slurm job J)
  --readme-line TEXT    an extra line at the end of the entry block (repeatable)
  --tar-sha256 HEX      the frozen source tarball's SHA-256, named in the entry block
  --json                machine-readable JSON on stdout
