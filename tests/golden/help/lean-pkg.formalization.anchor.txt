usage: lean-pkg formalization anchor [-h] [--arxiv ID] [--from-file E-PRINT] [--fetch]
                                     [--compare-tex LOCAL.tex] [--accept-diff REASON]
                                     [--main-tex PATH] [--write] [--agent AGENT] [--json]
                                     [--commit] [--push] [--no-commit]
                                     [package]

`lean-pkg formalization anchor NAME --arxiv <id>v<N> (--from-file E-PRINT | --fetch) [--compare-
tex LOCAL.tex [--accept-diff REASON]] [--main-tex PATH] [--write]`: bind the companion to one
posted arXiv version. Reads the e-print (gzip'd tar, gzip'd .tex or tar; PDF-only is refused) in
memory, hashes it and its .tex/.bib/.bbl/.sty files, finds the main .tex (\documentclass),
compares it with LOCAL.tex and records it all in data/source-baselines/arXiv-<id>v<N>.json.
Without --write: a dry run. --write refuses unless the e-print is tied to the manuscript
coverage.yaml is bound to (same version, a matching bound sha256, or --compare-tex identical /
--accept-diff); a move to another version prints the `claims rebase` command. Never writes the
registry; never commits

positional arguments:
  package               the package to anchor

options:
  -h, --help            show this help message and exit
  --arxiv ID            the arXiv id WITH its version (<id>v<N> or arXiv:<id>v<N>); unversioned
                        ids are refused
  --from-file E-PRINT   the e-print as downloaded from arxiv.org/e-print/<id>v<N> (offline; no
                        network)
  --fetch               download the e-print over HTTPS (60 s timeout, 64 MiB cap) and the arXiv
                        API entry of that version; the only network access this command makes
  --compare-tex LOCAL.tex
                        compare this local .tex with the e-print's main .tex (line endings and
                        trailing whitespace normalised); the differing lines are shown
  --accept-diff REASON  with --compare-tex: anchor although the files differ; the reason is
                        recorded
  --main-tex PATH       the e-print's main .tex when more than one file carries \documentclass
  --write               write the source-baseline record, coverage.yaml manuscript.version and the
                        formalization.yaml source id (never the registry; not committed); without
                        it a dry run
  --agent AGENT         lease holder, if one is live
  --json                machine-readable JSON on stdout
  --commit              write commands: pull --ff-only, then commit the registry files (default:
                        $LEAN_PKG_COMMIT=1)
  --push                --commit, then push to origin (default: $LEAN_PKG_PUSH=1)
  --no-commit           never commit or push (overrides the env)
