usage: lean-pkg index check [-h] [--clone] [--repo DIR] [--index INDEX] [--json] [NAME ...]

positional arguments:
  NAME

options:
  -h, --help     show this help message and exit
  --clone        clone each entry's repo at the pin into a temp dir
  --repo DIR     local clone for a single NAME (never modified) (old spelling --repo-dir, kept
                 working)
  --index INDEX  index root (default: $LEAN_PKG_INDEX, else index/ beside the registry when
                 present, else ./index)
  --json         machine-readable JSON on stdout
