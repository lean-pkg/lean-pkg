usage: lean-pkg promote [-h] [--yes] [--skip-public-safety] [--agent AGENT] [--json] [--commit]
                        [--push] [--no-commit]
                        name

positional arguments:
  name

options:
  -h, --help            show this help message and exit
  --yes                 execute: gh repo edit --visibility public (ONE-WAY); first fetches
                        origin's branches, tags and pull-request heads so the public-safety scan
                        covers them (a failed fetch refuses)
  --skip-public-safety  do not run the public-safety scan of the tree and history (a WARN line
                        instead; the scan covers the whole repository when the package is a
                        subdirectory of it)
  --agent AGENT         with --yes: the agent acting (recorded as the promoted event's actor);
                        another agent's live lease then refuses
  --json                machine-readable JSON on stdout
  --commit              write commands: pull --ff-only, then commit the registry files (default:
                        $LEAN_PKG_COMMIT=1)
  --push                --commit, then push to origin (default: $LEAN_PKG_PUSH=1)
  --no-commit           never commit or push (overrides the env)
