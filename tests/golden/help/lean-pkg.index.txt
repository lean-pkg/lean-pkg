usage: lean-pkg index [-h] [--json] [--commit] [--push] [--no-commit]
                      {add,check,render,migrate} ...

positional arguments:
  {add,check,render,migrate}
    add                 write <index>/<name>/entry.yaml from a clone at the pin
    check               static check, or re-derive entries from bytes at the pin; exit 0/1/2
    render              write the Markdown table (default <index>/README.md)
    migrate             rewrite index-entry/1 entries as index-entry/2 (claims derived)

options:
  -h, --help            show this help message and exit
  --json                machine-readable JSON on stdout
  --commit              write commands: pull --ff-only, then commit the registry files (default:
                        $LEAN_PKG_COMMIT=1)
  --push                --commit, then push to origin (default: $LEAN_PKG_PUSH=1)
  --no-commit           never commit or push (overrides the env)
