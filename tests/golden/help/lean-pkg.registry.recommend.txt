usage: lean-pkg registry recommend [-h] [--reason REASON] [--json] [--commit] [--push]
                                   [--no-commit]
                                   VERSION

positional arguments:
  VERSION          X.Y.Z: the release every machine using this registry should run (stored as the
                   top-level lean_pkg.recommended; event registry-recommended)

options:
  -h, --help       show this help message and exit
  --reason REASON  free text recorded with the event
  --json           machine-readable JSON on stdout
  --commit         write commands: pull --ff-only, then commit the registry files (default:
                   $LEAN_PKG_COMMIT=1)
  --push           --commit, then push to origin (default: $LEAN_PKG_PUSH=1)
  --no-commit      never commit or push (overrides the env)
