| Form | What it does | Key flags |
|---|---|---|
| `list` | static table, script-friendly. `--only` filters packages, never fields: the table or the `--json` dump holds just the named packages, each with its full record, cached claims included (the dump's shape is unchanged: `version` plus `packages` holding just those records); an unknown name exits 1 like `status`. `--fields` trims fields, never packages: each package record is cut to those keys with the validation and dotted paths of `status --fields` (an unknown field exits 2 listing the valid keys); `--json` keeps the dump's shape and adds a `fields` list, text mode prints each package's selected keys as YAML instead of the table. Combine them for one value of one package: `list --json --only NAME --fields status`. `--no-claims` drops the bulk cached arrays, the keys tagged `[bulk]` in [Package record](../cli.md#package-record) (today `claims`), from each record and leaves every other key and the dump's shape unchanged; `--json` adds an `omitted` list naming them | `--json` `[--only NAME[,NAME]]` `[--fields a,b,c]` `[--no-claims]` |
