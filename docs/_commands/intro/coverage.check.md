| `coverage check NAME` | read-only: validate `coverage.yaml` (schema `coverage/1`, committed at `HEAD`; `--file PATH` checks a working copy) against `claims.yaml` and the receipts at `HEAD`: exact key sets, closed enums (`same-assumptions`, `inputs-supplied`, `outside`; cluster `easley`), duplicate keys refused, claim ids that exist and are not superseded, inputs for every `inputs-supplied` row, at least one `outside` row or `nothing_excluded: {reason}`, a posted manuscript version (`arXiv:IDvN` or `{repo, commit, sha256}`; `unposted` only with `--allow-private-manuscript`), every `compute` job a committed Slurm receipt; the lab's `lean-scope-page` rules that apply: no placeholder text (`FILL-ME`, `TODO`, `TBD`, `FIXME`, `XXX`), every named claim's `file` committed at `HEAD`, every theorem of the recorded comparator receipt the declaration of a claim some row names, every configuration there with `definition_names` carrying `judged_as.reviewer`; `kind: library` (no manuscript; rows `{title, claims, note?}`, the library's main results; `manuscript`, `nothing_excluded` and paper row keys refused); exit 0 or 1; `--json` `{ok, name, file, kind, rows, counts, manuscript, private_manuscript, errors[], warnings[]}` (`manuscript` and `counts` null for a library); a warning, never an error, for each assumption a theorem mapped by a `same-assumptions` or `inputs-supplied` row takes that is not listed: a binder headed by a `Prop` `def` of the package (its module's file committed at `HEAD`), per the `hyp-decl` lines of the gate receipt's sealed verify log, that neither the claim's `hypotheses` nor a `{hypothesis, text}` input of the row names (proposal 0003, open question 7; no log or no `hyp-probe/1` section: no warning; [Unlisted assumptions](../page.md#unlisted-assumptions)) ([The verification page](../page.md#coverageyaml)) | `[--file PATH]` `[--allow-private-manuscript]` |
| `coverage check --file PATH` (no `NAME`) | the offline form (#328), before the package is registered or the files are committed: reads no registry record and no receipt. Runs every check above that needs neither: the `coverage/1` schema with its length limits and placeholder rule, the manuscript version (`--allow-private-manuscript` as above), `lean_pkg_version`; with `--claims PATH`, the claims file's `claims/1` schema (the coverage `package` must be its `package`), each row's claim ids (present, not superseded) and a warning for each `reusable` claim no row names; with `--comparator PATH` (repeatable: pass every configuration), each configuration theorem the declaration of a claim a row names (a configuration `lean-pkg-signoff.json` beside the coverage file marks `smoke` is exempt; skipped when a named claim's Lean file is not readable under the coverage file's directory). The checks that need the registry record, the checkout at `HEAD` or a receipt (compute receipts, claim files committed at `HEAD`, definition sign-off, the e-print baseline) are listed as `skipped`, as are those whose input was not given. `NAME` is optional only here: with `NAME`, `--file` keeps its meaning (claim ids and receipts read at `HEAD`), and `--claims`/`--comparator` are a usage error (exit 2); no `NAME` and no `--file` is a usage error too. The verdict is the first and the last line; exit 0 or 1; `--json` the payload above plus `offline: true`, `claims_file`, `comparator[]`, `checks[{check, status pass\|fail\|warn\|skipped, detail}]`, `skipped[]` (`name` is the file's `package`). [`verify`](verify.md) runs this check at `HEAD` as its preflight | `--file PATH` `[--claims PATH]` `[--comparator PATH ...]` `[--allow-private-manuscript]` |
