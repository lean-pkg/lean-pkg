| Form | What it does | Key flags |
|---|---|---|
| `publish NAME --dry-run` | read-only release checklist from verified-private to listed (named `publish` because `release` releases a lease): the `page --check` line (a WARN while the package has no `coverage.yaml` and no page block, a failure for an unbacked Easley sentence; JSON `page`); the promote checklist, claims ledger included (for a `verified-private` package; `--json` `claims_ledger` as in `promote`, null otherwise; a public one only needs HEAD pushed), consent recorded, `license_spdx` set and the LICENSE text matching it, `formalization.yaml` present, schema-valid and equal to the render (stale evidence is a `✗`; missing is a `✗` for `upstream_target: palomar`, else `WARN`), `claims.yaml` synced at HEAD when tracked, a Lake package name in the lakefile, a tag at HEAD (`WARN`); then the exact next commands (`promote`, `promote --yes`, `git tag`/push, `record reservoir-listed`, `record palomar-submitted`; the tag push names the checkout's GitHub remote, found by URL among `git remote -v` since `origin` may be a private mirror, says "after promote" while the package is not public, and says so when no remote points at GitHub). The git-ignored evidence `WARN` of `promote` (for any status) and `--json` `ignored_evidence[]` {path, rule}. Exit 0 when no `✗`, else 1; `--json`: `ready`, `checklist[]`, `next[]`, `manuscript_findings` (the ledger's summary of what the formalization found in the manuscript, also one text line `manuscript findings (what the formalization found): ...` when there is one; never a checklist item, never a status; [Lifecycle](../lifecycle.md#manuscript-findings)). Without `--dry-run`: refused (exit 2), dry-run only in this version. `--public-safety` adds the `public-safety` scan as a checklist line (the promote refusal text when it has hits; `--json` gains `public_safety`) and implies `--dry-run`; a `WARN` item `palomar: not submittable ...` when `palomar check` finds error gaps at HEAD (JSON `palomar_check`, as in `gate --check`); it never makes the checklist fail | `--dry-run` `[--public-safety]` |
