| Form | What it does | Key flags |
|---|---|---|
| `verify NAME` | the newcomer's one step from a committed package to `verified-private` on this machine, at the checkout's `HEAD` X: refused first (nothing run) for an unknown package, a checkout that is not a clean commit, no committed verify script, no comparator configuration, a status the gate cannot reach. Then **step 0, the preflight** (read-only, also under `--dry-run`): the claims/1 check [`claims check --file`](claims-check.md) runs, on the claims file committed at `HEAD`, and, when `coverage.yaml` is committed, the offline [`coverage check`](coverage-check.md) against the claims file and the comparator configurations committed at `HEAD` (schema and length limits, claim ids, every comparator theorem the declaration of a claim a row names); placeholder text and an unposted manuscript are warnings here, since `coverage check` and `page` refuse them later. A refusal stops verify with that message before any receipt work: no receipt, no unit, nothing written. Files present only in the working tree are never read. Step 0 also runs the import scan of [`palomar port-modules`](palomar-port-modules.md) at `HEAD`: a module-headed file of the package that imports a non-module file of the package (which fails to build: a module cannot import a non-module) is a warning, never a refusal, naming the files and `next: lean-pkg palomar port-modules NAME --dry-run`; it is skipped silently when the tree at `HEAD` cannot be read. Then, each printed and run as its own invocation: (1) the comparator receipt, (2) the lower-tier receipt at the same commit, (3) for an `active` package the move to `gate-pending`, (4) the gate (`--regate` for a gated package). A receipt of X already present is reused; nothing is committed. `--json` `steps[]` begins with `{step: "0/3 preflight", rc, output {ok, claims, coverage, module_imports[{file, line, module, target}], warnings[]}}` | `[--dry-run]` `[--work-dir DIR]` `[--unit U]` `[--script FILE]` `[--judges N]` `[--agent A]` `[--reason TEXT]` |
