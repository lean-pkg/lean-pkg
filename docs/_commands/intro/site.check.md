| Form | What it does | Key flags |
|---|---|---|
| `site check NAME` | read-only, [proposal 0012](../proposals/0012-site-standard.md) phase 1: the package's documentation site in `DIR` (default `docs`), of any kind: `static` (`DIR/.nojekyll`), `mkdocs` (`mkdocs.yml` whose `docs_dir` is `DIR`) or `jekyll`. Fails on a generated page (`verification.md`, `coverage.md`) stale against `page --site` or not linked, Markdown inside an HTML block, mathematics without MathJax in the head, the noindex meta tag missing while the record's visibility is private (or present once public), a served copy of a build input, and an `index.html` shadowing `index.md`; warns about the opt-in key, counts, versions and commits written by hand outside generated blocks, a hand-written page under a generated name, and unclassified served files. Verdict first; exit 0 or 1; `--json` `{ok, name, dir, kind, opt_in, registry, generated[], stale[], links, html_blocks[], counts[], exemptions[], math, noindex, served, shadowing_index_html, binding, snapshot, problems[], warnings[]}` ([The site standard](../site.md)) | `[--dir DIR]` `[--repo DIR]` `[--allow-private-manuscript]` |
| `site check --no-registry` (or no `NAME`) | the CI form: the repository is the current directory and no registry record is read, so the generated-page comparison and the noindex-against-visibility check are listed as not checked; `--repo` needs `NAME` (exit 2) | `[--dir DIR]` |
