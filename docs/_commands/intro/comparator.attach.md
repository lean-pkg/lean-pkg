| Form | What it does | Key flags |
|---|---|---|
| `comparator attach NAME` | attach comparator evidence to a gated package (event `comparator-attached`); `comparator check NAME` validates only (the same `✓` binding lines as `gate --check`, plus the comparator ones; JSON adds `checks[]` and `head`); same private-string scan, dirty-tree `WARN`, off-default-branch `WARN` and git-ignored evidence `WARN` (`ignored_evidence[]`) as `gate`; without `--receipt` a usage error (exit 2). When `.lean-receipts/` already holds a different receipt for the same commit it refuses, naming the file; `--replace` moves that file to `.lean-receipts/<commit12>-comparator.replaced-<UTC stamp>.json` (never overwriting one), copies the new receipt in, and records `comparator-replaced` with `replaced` (the kept file) in history, the event log and the JSON; with nothing to replace it is a plain attach. `comparator check NAME --repo DIR` validates against the checkout `DIR` (a worktree or feature branch where the receipt was made) instead of the registered `local_path`, with the rules of `gate --check --repo`: this call only, never saved, stderr note, JSON `repo_override` {path, registered_path, remote_match} (`null` without it), remote matching as there; attaching refuses `--repo` (exit 2); see [Pre-checking a receipt made in another checkout](../comparator.md#pre-checking-a-receipt-made-in-another-checkout) | `--receipt PATH` `[--replace]` `[--refuse-private]` `[--refuse-dirty]`; check: `--receipt PATH` `[--repo DIR]` |
