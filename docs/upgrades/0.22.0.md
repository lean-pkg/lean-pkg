# Upgrading to 0.22.0 (from 0.21.0)

The changes merged after 0.21.0 that a package author should know about.
The machine-readable record is [0.22.0.yaml](0.22.0.yaml). This page is
filled in as pull requests merge, until 0.22.0 is cut. `lean-pkg doctor
--upgrade-from 0.21.0` prints the mechanical part, and the
[design](../design/upgrade-preflight.md) explains how the record is used.
The name 0.22.0 is provisional: the release is named by what it holds
(RELEASING.md, "When to tag"), and the record is renamed with it.

Nothing so far is required of a package author.

PR #321 (documentation: the 2026-10 improvement plan, with an issue for each
row, #310 to #320, and proposals 0002 and 0003 marked accepted; no code
changes) was read for this record; it changes nothing for a package author.
