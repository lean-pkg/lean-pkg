# Upgrading to 0.29.0 (from 0.28.0)

The changes merged after 0.28.0 that a package author should know about.
The machine-readable record is [0.29.0.yaml](0.29.0.yaml). This page is
filled in as pull requests merge, until 0.29.0 is cut. `lean-pkg doctor
--upgrade-from 0.28.0` prints the mechanical part, and the
[design](../design/upgrade-preflight.md) explains how the record is used.
The name 0.29.0 is provisional: the release is named by what it holds
(RELEASING.md, "When to tag"), and the record is renamed with it.

Nothing so far is required of a package author.

## Nothing required

| Entry | PR | What changed | What to do |
|---|---|---|---|
| `site-check` | #444 | New read-only `lean-pkg site check`, phase 1 of the site standard ([proposal 0012](../proposals/0012-site-standard.md)): it checks a Jekyll, MkDocs or static site for stale or unlinked generated pages, Markdown inside HTML blocks, missing MathJax, the noindex while private, served copies of build inputs and a shadowing `index.html`, and warns about hand-written counts ([the site standard](../site.md)). | Nothing. Run `lean-pkg site check NAME`, or `site check --no-registry` in the checkout (the CI form). |

PR #443 (documentation: proposal 0011 marked implemented in 0.28.0) was read for this record; it changes nothing for a package author.
