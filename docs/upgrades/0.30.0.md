# Upgrading to 0.30.0 (from 0.29.0)

The changes merged after 0.29.0 that a package author should know about.
The machine-readable record is [0.30.0.yaml](0.30.0.yaml). This page is
filled in as pull requests merge, until 0.30.0 is cut. `lean-pkg doctor
--upgrade-from 0.29.0` prints the mechanical part, and the
[design](../design/upgrade-preflight.md) explains how the record is used.
The name 0.30.0 is provisional: the release is named by what it holds
(RELEASING.md, "When to tag"), and the record is renamed with it.

Nothing so far is required of a package author.

## Nothing required

| Entry | PR | What changed | What to do |
|---|---|---|---|
| `gate-next-claims-sync` | #450 | The writing `gate` ends with `next: lean-pkg claims sync NAME` when the registry's claims cache is not at the gated commit or `HEAD`; `gate --json` gains `next_command` ([gate](../commands/gate.md)). | Nothing. Run the printed command after a gate. |
| `agent-env-default` | #449 | `gate` (not `gate --check`) and `update` take their `--agent` from `$LEAN_PKG_AGENT` when none is given, checked against the live lease as a typed `--agent` is ([environment](../commands/help.md)). | Nothing. Export `LEAN_PKG_AGENT=HOLDER` instead of passing `--agent HOLDER` each time; unset it where it means something else. |
