# Upgrading to 0.13.0 (from 0.12.0)

The changes merged after 0.12.0 that a package author should know about.
The machine-readable record is [0.13.0.yaml](0.13.0.yaml). This page is
filled in as pull requests merge, until 0.13.0 is cut. `lean-pkg doctor
--upgrade-from 0.12.0` prints the mechanical part, and the
[design](../design/upgrade-preflight.md) explains how the record is used.

| Entry | PR | What changed | What to do |
|---|---|---|---|
| `receipt-container-image` | #245 | Receipts record the container image a job ran in as the additive key `container` (the SIF's SHA-256 or the OCI digest); `receipt check` and the page show it. A receipt without it is unchanged. | Optional: regenerate `verify.sbatch` with `lean-pkg receipt slurm --template` to record the image. |
