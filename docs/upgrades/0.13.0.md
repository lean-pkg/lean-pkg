# Upgrading to 0.13.0 (from 0.12.0)

The changes merged after 0.12.0 that a package author should know about.
The machine-readable record is [0.13.0.yaml](0.13.0.yaml). This page is
filled in as pull requests merge, until 0.13.0 is cut. `lean-pkg doctor
--upgrade-from 0.12.0` prints the mechanical part, and the
[design](../design/upgrade-preflight.md) explains how the record is used.

One change asks for a step, and only from a package that committed the
large-artifact recipe's packing script:

| Entry | PR | What changed | What to do |
|---|---|---|---|
| `extract-disabled-lean-warning` | #239 | `lean-pkg-extract plan` warns about `*.lean.<suffix>` files under a root that it excludes or refuses (disabled negative fixtures, which the import check does not read), pointing at [Disabled negative fixtures](../extract.md#disabled-negative-fixtures-after-a-namespace-or-import-transport) and `lean_diag`. `ok` and the exit code do not change. | Nothing is required. |
| `dup-constants-path-subdir-deps` | #240 | `lean_pkg.dup_constants` finds `path` dependencies at their `dir` (e.g. `vendor/NAME`) and `git` dependencies with a `subDir`; 0.12.0 refused such projects before the audit ([duplicate constants](../duplicate-constants.md)). | Nothing is required. |
| `large-artifact-pack-guards` | #244 | `pack-artifacts.sh` in [docs/receipts.md](../receipts.md) refuses an output directory that is the raw tree or lies inside it (or the reverse), and two paths in the raw tree that are hardlinks of one file. Before, a nested output was packed into its own archive, and a hardlink packed but the collector refused the archive. | Replace a committed copy with the page's current script. Keep the output next to the raw tree; copy a raw tree with internal hardlinks without links before packing. |

PRs #238 (proposal 0004, a math LTS stack, as a draft) and #242
(proposal 0003, conditional claims and discharge, as a draft with a
prototype) change nothing for a package author.
