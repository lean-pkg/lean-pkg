# Upgrading to 0.13.0 (from 0.12.0)

The changes merged after 0.12.0 that a package author should know about.
The machine-readable record is [0.13.0.yaml](0.13.0.yaml). This page is
filled in as pull requests merge, until 0.13.0 is cut. `lean-pkg doctor
--upgrade-from 0.12.0` prints the mechanical part, and the
[design](../design/upgrade-preflight.md) explains how the record is used.

No change so far asks for a step.

| Entry | PR | What changed |
|---|---|---|
| `extract-disabled-lean-warning` | #239 | `lean-pkg-extract plan` warns about `*.lean.<suffix>` files under a root that it excludes or refuses (disabled negative fixtures, which the import check does not read), pointing at [Disabled negative fixtures](../extract.md#disabled-negative-fixtures-after-a-namespace-or-import-transport) and `lean_diag`. `ok` and the exit code do not change. |
| `dup-constants-path-subdir-deps` | #240 | `lean_pkg.dup_constants` finds `path` dependencies at their `dir` (e.g. `vendor/NAME`) and `git` dependencies with a `subDir`; 0.12.0 refused such projects before the audit ([duplicate constants](../duplicate-constants.md)). |

PR #238 (proposal 0004, a math LTS stack, as a draft) was read for this
record; it changes nothing for a package author.
