# Upgrading to 0.26.0 (from 0.25.0)

The changes merged after 0.25.0 that a package author should know about.
The machine-readable record is [0.26.0.yaml](0.26.0.yaml). This page is
filled in as pull requests merge, until 0.26.0 is cut. `lean-pkg doctor
--upgrade-from 0.25.0` prints the mechanical part, and the
[design](../design/upgrade-preflight.md) explains how the record is used.
The name 0.26.0 is provisional: the release is named by what it holds
(RELEASING.md, "When to tag"), and the record is renamed with it.

Nothing so far is required of a package author.
