# Upgrading to 0.31.0 (from 0.30.0)

The changes merged after 0.30.0 that a package author should know about.
The machine-readable record is [0.31.0.yaml](0.31.0.yaml). This page is
filled in as pull requests merge, until 0.31.0 is cut. `lean-pkg doctor
--upgrade-from 0.30.0` prints the mechanical part, and the
[design](../design/upgrade-preflight.md) explains how the record is used.
The name 0.31.0 is provisional: the release is named by what it holds
(RELEASING.md, "When to tag"), and the record is renamed with it.

Nothing so far is required of a package author.

## Nothing required

| Entry | PR | What changed | What to do |
|---|---|---|---|
| `receipt-systemd-oom-refusal` | #459 | `receipt systemd` refuses an OOM-killed unit naming its memory peak, its `MemoryMax` and how to raise the cap (`lean-pkg verify NAME --memory-max SIZE`, with a suggested size); the memory WARN is not printed for such a unit ([receipt systemd](../receipts.md#a-lower-tier-receipt-from-a-systemd-unit)). | Nothing. A script matching the old refusal text should match the new wording. |
