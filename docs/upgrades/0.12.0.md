# Upgrading to 0.12.0 (from 0.11.0)

The changes merged after 0.11.0 that a package author should know about.
The machine-readable record is [0.12.0.yaml](0.12.0.yaml). This page is
filled in as pull requests merge, until 0.12.0 is cut. `lean-pkg doctor
--upgrade-from 0.11.0` prints the mechanical part, and the
[design](../design/upgrade-preflight.md) explains how the record is used.

One change asks for a step, and only from a package whose Challenge
module is an umbrella (a file holding only `import` lines):

| Entry | PR | What changed | What to do |
|---|---|---|---|
| `page-umbrella-challenge-statements` | #226 | `page` follows the umbrella's imports through the package's own files at the gate-bound commit and shows each result's Lean statement from the file that declares it, linked at its line. 0.11.0 said the statement "could not be read reliably" for every result of such a package. | Run `lean-pkg page NAME --write` once and commit the README. Other packages: nothing. |

Two changes alter what a command does by default:

| Entry | PR | What changed | What to do |
|---|---|---|---|
| `page-write-turns-on-docs-descendants` | #222 | On a gated package whose record does not set `docs_descendants`, the first `page --write` sets it with `update --accept-docs-descendants`. That is a registry write with its own event. | Nothing. To keep the docs-only rule off, set `docs_descendants: false` first. |
| `comparator-workstation-default` | #222 | When no allow-list is set and the machine has no Slurm, that machine may produce comparator receipts. | Set `COMPARATOR_RECEIPT_WORKSTATION_DEFAULT=0` to keep the old behaviour. |

Other changes:

| Entry | PR | What changed |
|---|---|---|
| `command-tree-stage-2` | #222 | New commands, each with its old spelling kept as a permanent alias: `verify NAME`, `repo export` and `repo adopt`, `publish --yes`, `comparator check`, `comparator coverage`, `comparator migrate-signoff`, `receipt comparator`, `verify-receipts`, and `register --license-spdx`. The root `--help` is now tiered. The command reference has one page per command, so `promote.md` is now `publish.md` and `comparator-receipt.md` is now `receipt-comparator.md`. |
| `install-path-redaction` | #222 | Receipts and stage logs write `<lean-pkg>` and `<elan>` in place of install paths. |
| `comparator-rerun-after-verify-sh` | #222 | Re-running the comparator receipt after `verify.sh` has cleaned `.lake/build` no longer refuses. |
| `lean-diag-negative-tests` | #219 | `lean_pkg.lean_diag`, a strict parser of Lean diagnostics for negative tests ([negative tests](../negative-tests.md)). |
| `doctor-upgrade-preflight` | #223, #228 | `lean-pkg doctor --upgrade-from OLD`: this preflight, the mechanical delta plus these records. An option of a mode that became its own command reads as moved to that command. |

PRs #220 (index data), #221 and #225 (docs), #224 (the changelog layout),
#227 (the released-CHANGELOG check in `make check` and CI), #228 (the
preflight follow-up above, this record and test rows) and #229 (this
record's completion, the pull request template) were read for this record; none needs anything from a package author.
