# Upgrading to 0.28.0 (from 0.27.0)

The changes merged after 0.27.0 that a package author should know about.
The machine-readable record is [0.28.0.yaml](0.28.0.yaml). This page is
filled in as pull requests merge, until 0.28.0 is cut. `lean-pkg doctor
--upgrade-from 0.27.0` prints the mechanical part, and the
[design](../design/upgrade-preflight.md) explains how the record is used.
The name 0.28.0 is provisional: the release is named by what it holds
(RELEASING.md, "When to tag"), and the record is renamed with it.

Nothing so far is required of a package author; a `coverage.yaml` that names a row `witness`, or a
`claims.yaml` that sets `witness` on a claim without hypotheses, needs this release or later.

## Nothing required

| Entry | PR | What changed | What to do |
|---|---|---|---|
| `coverage-row-witness` | #437 | A `coverage.yaml` row may name a non-vacuity witness, `witness: <claim id>`, the `witness` in `claims.yaml` of one of its claims, which may now be any claim, not only a conditional one ([proposal 0011](../proposals/0011-nonvacuity-witness-on-coverage-rows.md)). The page then says **Hypotheses can be met.** with the probe's state ([a witness](../page.md#hypotheses-that-can-be-met-a-witness)). | Nothing for files without the key. A file that uses it, or a claim with only `witness`, needs this release or later (an older lean-pkg refuses them): raise the CI pin first. |
| `page-internal-built-not-compared` | #441 | A result whose unverified claims are internal theorems or lemmas the build accepted but no comparator judged reads **Built, not compared.** on the page instead of "Not yet verified ... work in progress" ([the page](../page.md#the-papers-statement)). Counts and ledger statuses are unchanged. | Nothing. Re-run `lean-pkg page NAME --write` (and `--site`/`--html`) to refresh a committed page; `page --check` reports the old wording as stale until then. |

PR #439 (docs: a one-line note that lean-pkg is unrelated to Lean 3's `leanpkg`) was read for this record; it changes nothing for a package author.
PR #440 (proposal 0012, a package site standard, accepted; nothing implemented yet) was read for this record; it changes nothing for a package author.
