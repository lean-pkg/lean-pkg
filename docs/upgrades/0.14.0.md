# Upgrading to 0.14.0 (from 0.13.0)

The changes merged after 0.13.0 that a package author should know about.
The machine-readable record is [0.14.0.yaml](0.14.0.yaml). This page is
filled in as pull requests merge, until 0.14.0 is cut. `lean-pkg doctor
--upgrade-from 0.13.0` prints the mechanical part, and the
[design](../design/upgrade-preflight.md) explains how the record is used.

Nothing so far asks anything of a package author. One new check is optional:

| Entry | PR | What changed | What to do |
|---|---|---|---|
| `blueprint-check-checkdecls` | #260 | New read-only `lean-pkg blueprint check NAME`: it runs [checkdecls](https://github.com/PatrickMassot/checkdecls) on the blueprint's `blueprint/lean_decls` after `lake build` at HEAD, reports the missing names, and checks that every claim whose `decl` the blueprint names is a declaration checkdecls accepts. A package without a blueprint is skipped. See [page: blueprint cross-check](../page.md#blueprint-cross-check). | Optional: add the pinned `require checkdecls` line from that section, run `lake update checkdecls`, commit the lakefile and `lake-manifest.json`, then run the command. |

PRs #257 (a Codespaces dev container for the π-λ tutorial), #258 (the
lts-2026.10 stage 0 matrix results, as docs) and #259 (lts-2026.10
declared, as docs) were read for this record; none needs anything from a
package author.
