# Upgrading to 0.14.0 (from 0.13.0)

The changes merged after 0.13.0 that a package author should know about.
The machine-readable record is [0.14.0.yaml](0.14.0.yaml). This page is
filled in as pull requests merge, until 0.14.0 is cut. `lean-pkg doctor
--upgrade-from 0.13.0` prints the mechanical part, and the
[design](../design/upgrade-preflight.md) explains how the record is used.

Nothing so far asks anything of a package author.

PRs #257 (a Codespaces dev container for the π-λ tutorial) and #258 (the
lts-2026.10 stage 0 matrix results, as docs) were read for this record;
neither needs anything from a package author.
