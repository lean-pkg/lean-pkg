# Upgrading to 0.27.0 (from 0.26.0)

The changes merged after 0.26.0 that a package author should know about.
The machine-readable record is [0.27.0.yaml](0.27.0.yaml). This page is
filled in as pull requests merge, until 0.27.0 is cut. `lean-pkg doctor
--upgrade-from 0.26.0` prints the mechanical part, and the
[design](../design/upgrade-preflight.md) explains how the record is used.
The name 0.27.0 is provisional: the release is named by what it holds
(RELEASING.md, "When to tag"), and the record is renamed with it.

A site whose hand-written pages hold Markdown inside an HTML block without a
`markdown` attribute fails `page --check --site` from this release:

## Act before you check a page with --site

| Entry | PR | What changed | What to do |
|---|---|---|---|
| `page-check-site-html-blocks` | #428 | `page --check --site DIR` also reads every hand-written `*.md` under `DIR`: a `<details>`, `<div>`, `<section>`, `<aside>`, `<article>` or `<blockquote>` block that holds Markdown without a `markdown` attribute exits 1, naming the file and line, since GitHub Pages and MkDocs publish it as literal text ([hand-written pages](../page.md#hand-written-pages-beside-the-generated-ones)). `--check --site --json` gains `html_blocks[]`. | Run `page --check --site DIR` once; write each block it names as `<details markdown="1">` (a bare `markdown` also works), with a blank line before the Markdown inside. |

## Nothing required

| Entry | PR | What changed | What to do |
|---|---|---|---|
| `coverage-row-witness` | #433 | A `coverage.yaml` row may name a non-vacuity witness, `witness: <claim id>`, the `witness` in `claims.yaml` of one of its claims, which may now be any claim, not only a conditional one ([proposal 0011](../proposals/0011-nonvacuity-witness-on-coverage-rows.md)). The page then says **Hypotheses can be met.** with the probe's state ([a witness](../page.md#hypotheses-that-can-be-met-a-witness)). | Nothing for files without the key. A file that uses it, or a claim with only `witness`, needs this release or later (an older lean-pkg refuses them): raise the CI pin first. |
