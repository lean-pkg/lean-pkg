# Upgrading to 0.27.0 (from 0.26.0)

The changes merged after 0.26.0 that a package author should know about.
The machine-readable record is [0.27.0.yaml](0.27.0.yaml). This page is
filled in as pull requests merge, until 0.27.0 is cut. `lean-pkg doctor
--upgrade-from 0.26.0` prints the mechanical part, and the
[design](../design/upgrade-preflight.md) explains how the record is used.
The name 0.27.0 is provisional: the release is named by what it holds
(RELEASING.md, "When to tag"), and the record is renamed with it.

Nothing so far is required of a package author.

PR #427 (docs: links on the documentation site that returned 404) was read for this record; it changes nothing for a package author.
